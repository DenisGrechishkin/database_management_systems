# Практикум по СУБД

Репозиторий содержит полный цикл лабораторных работ по дисциплине **«Системы управления базами данных»**. 
Проект демонстрирует практические навыки проектирования, запросов, оптимизации и программирования в PostgreSQL. 
---

## Ключевые компетенции
Применённые практики:
  - Сложные `JOIN`, `CTE`, оконные функции, агрегация, динамическая генерация тестовых данных
  - **Моделирование & Качество данных**: Нормализация, связи `1:N` / `N:N`, `CHECK`-ограничения, валидация форматов (телефоны, ФИО) |
  - **Оптимизация производительности**: Индексы, анализ планов выполнения (`EXPLAIN ANALYZE`), оценка селективности, ускорение выборок |
  - **Целостность & Консистентность**: Уровни изоляции транзакций, предотвращение аномалий (`Dirty Read`, `Phantom`), `COMMIT`/`ROLLBACK` |
  - **Автоматизация бизнес-логики**: Триггеры, процедуры, функции, курсоры, обработка исключений на `PL/pgSQL` |

---

## Структура лабораторных работ:

| № | Тема | Решаемые аналитические задачи |
|:---:|:---|:---|
| **ЛР1** | Объединяющие и вложенные запросы | Построение витрин данных, агрегация по группам, фильтрация, создание `VIEW` для упрощения доступа к данным |
| **ЛР2** | Логическое и физическое проектирование БД | Исправление связей `1:1` → `N:N`, проектирование справочников курсов и сертификатов, настройка ограничений целостности |
| **ЛР3** | Операторы модификации данных | Массовая вставка (`INSERT`), сложные обновления (`UPDATE` с подзапросами), генерация и валидация контактов, очистка данных |
| **ЛР4** | Программирование на PL/pgSQL | Автоматизация расчётов (средний балл, зарплаты), симуляция процессов (турнир), триггеры на валидацию ввода и защиту от некорректных операций |
| **ЛР5** | Индексы и транзакции | Сравнение времени выполнения до/после индексации, анализ планов запросов, тестирование уровней изоляции (`READ COMMITTED`, `SERIALIZABLE`), фиксация/откат изменений |

---

## Технологический стек:
- **СУБД:** PostgreSQL
- **Язык запросов:** SQL (PostgreSQL dialect)
- **Процедурный язык:** PL/pgSQL
- **Клиент:** pgAdmin / DBeaver / psql
- **Документация:** Отчёты содержат скрипты, планы выполнения, сравнительные таблицы производительности и анализ аномалий
